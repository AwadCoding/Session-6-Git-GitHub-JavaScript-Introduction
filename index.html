01 / VERSION CONTROL

Why Version Control?

and now it is broken.

  • How can teammates work together?
  • Where is the project's history?
THE SOLUTION

02 / THE TOOLS

Git vs GitHub

GIT

Git

The version control system

  • Installed and used locally
  • Tracks changes in project files
  • Creates commits and branches
  • Works without GitHub
VS
GH

GitHub

A platform for hosting Git repositories

  • Hosts projects in the cloud
  • Makes sharing easier
  • Supports team collaboration
  • Includes Pull Requests and Issues
Git manages your project history. GitHub helps you host and collaborate on that project.

05 / HANDS-ON GIT

Let's Start Using Git

TERMINAL · INITIAL SETUP
git --version
git init
git status
STAGE YOUR FILES
# Stage one specific file
git add index.html

# Stage changes in this directory
git add .
git --version

Checks whether Git is installed.

git init

Initializes a new Git repository. Usually once per project.

git status

Shows the state of the working directory and staging area.

git add

Choose a specific file or stage current-directory changes with ..

Always understand what you are staging before creating a commit.

06 / SAVE YOUR PROGRESS

Save Your Progress

TERMINAL · COMMIT
git add .
git commit -m "Add portfolio homepage"
git log

A commit is a meaningful checkpoint in your project's history.

Avoid vague messages

“update”

“test”

“final”

“changes”

Be specific

Add homepage layout

Fix navigation links

Update contact section

Add responsive styles

A good commit message explains what changed.

07 / LOCAL TO REMOTE

Connecting Git to GitHub

LOCAL PROJECTYour computer
→
GIT COMMITSaved checkpoint
→
GITHUB REPOSITORYHosted online
FIRST PUSH
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
AFTER INITIAL SETUP
git add .
git commit -m "Describe your changes"
git push
branch -M main

Renames the current branch to main.

remote add origin

Adds a remote repository named origin.

push -u origin main

Pushes main and sets its upstream tracking branch.

Create the GitHub repository first. Replace the URL, authenticate if prompted, and note that first-push steps vary if the remote already has commits.

10 / CONNECTING FILES

How to Add JavaScript to Your Website

PROJECT STRUCTURE

my-website/
│
├── index.html
├── style.css
└── script.js
Keep structure, styling, and behavior organized in separate files.
INDEX.HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First JavaScript</title>
</head>
<body>
  <h1>Hello JavaScript</h1>
  <script src="script.js"></script>
</body>
</html>
SCRIPT.JS
console.log("Hello from JavaScript!");
Another common option: <script src="script.js" defer></script> in the head. The src value must point to the correct file path.

11 / JAVASCRIPT BASICS

Storing Information with JavaScript

letREASSIGNABLE

Use when the variable may be reassigned.

let username = "Mahmoud";
username = "Ahmed";
constNO REASSIGNMENT

Use when the binding should not be reassigned.

const community = "SCCI";

BASIC DATA TYPES

String"Mahmoud"
Number22
Booleantrue
Undefinedlet score;
Nullnull

Note: const prevents reassignment of the binding, not mutation of an object or array.
