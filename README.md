# SCCI'27 — Session 01: Git & JavaScript Fundamentals

A standalone, offline-ready, 16-slide presentation website for the SCCI'27 IT Community training session.

## Run the presentation

1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox, or Safari).
3. Use the controls or keyboard shortcuts to present.
4. Press `F` or use the fullscreen button for presentation mode.

No build process, package installation, server, or internet connection is required. The logo is included locally in `assets/`.

> The stylesheet includes an optional Google Fonts import for Manrope and DM Mono. If the computer is offline, the browser automatically falls back to system fonts; the presentation remains fully usable.

## Controls

- **Right Arrow / Space** — Next slide
- **Left Arrow** — Previous slide
- **Home** — First slide
- **End** — Last slide
- **N** — Toggle Egyptian Arabic presenter notes
- **F** — Toggle fullscreen
- Use the on-screen buttons for navigation, notes, and fullscreen.

The knowledge-check slide includes a reveal button; allow members to answer before revealing the sequence.

## Presenter notes

Open notes with `N` or the NOTES control. Notes are written in Egyptian Arabic and include teaching prompts, examples, questions, and transition guidance for each slide. The notes panel is closed by default, including when entering fullscreen.
